Set the C/C++ env for VS 2026 community edition:

C:\Program Files\Microsoft Visual Studio\18\Insiders\VC\Auxiliary\Build\vcvars32.bat"

Build the programs:

cl /EHsc drra_svc.cpp common.cpp agent_auth.cpp
cl /EHsc send_test_report.cpp common.cpp agent_auth.cpp
cl svcconfig.cpp
cl svccontrol.cpp
cl /EHsc list_all_apps.cpp
cl /EHsc list_all_patches.cpp
cl /EHsc list_defender_alerts.cpp

Build the message DLL

mc -U drra_messages.mc
rc -r drra_messages.rc
link -dll -noentry -out:drra_messages.dll drra_messages.res

Edit the settings:

Copy drra.ini to the same directory as the .exe files
and set [server] host to your report server.

Add the registry keys:

reg add HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\EventLog\Application\DataReelReportAgent
reg add HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\EventLog\Application\DataReelReportAgent /v EventMessageFile /t REG_SZ /d drra_messages.dll
reg add HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\EventLog\Application\DataReelReportAgent /v TypesSupported /t REG_DWORD /d 0x00000007

As Administrator:

Run the following command to install the service, test and uninstall:

drra_svc.exe install

svccontrol start DataReelReportAgent

svcconfig delete DataReelReportAgent
