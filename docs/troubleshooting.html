Troubleshooting

Start with the agent log. It has the result of the last report for each delivery method.

The log file

C:\ProgramData\DataReel\ReportingAgent\drra.log, readable by administrators. Run send_test_report.exe from an administrator command prompt in the install folder to get a fresh result right away.

Messages

MessageWhat to do
this agent is pending on the serverApprove the computer on the admin page (check the fingerprint in the log), or set the enrollment token
key_mismatchThe computer was reinstalled or its key changed. Delete its old registration on the admin page.
revokedAn admin revoked the computer. Approve it again if that was a mistake.
bad_timestampFix the clock on the computer or the server (allowed difference: max_clock_skew_seconds)
bad_tokenThe enrollment token in the agent INI does not match server.ini
bad_signatureThe report or request was changed on the way, or the key does not match the registration
error code 12007The server name cannot be resolved
error code 12029The server cannot be reached on that port
error code 12057The certificate revocation check failed: keep ignore_cert_revocation=1
error code 12175 or 12045Windows does not trust the server's TLS certificate
Unexpected answer from ... (HTTP 404)upload_path or register_path is wrong
Could not copy report to \\...The computer account, or the [cifs] user, cannot write to the share: share permissions, folder permissions, or SELinux on a Samba server
No share password, run: ... set-cifs-password[cifs] user= is set but its password was never saved
Could not connect to \\... as ..., error code 1326Wrong share user name or password: run set-cifs-password again
error code 53 (network path not found)The computer cannot reach the file server on port 445
error code 1219 (multiple connections)Another login to the same server with other credentials is open, for example a mapped drive in a desktop session
scp ... failed: Host key verification failedAdd the server to known_hosts_file, or use accept-new once

Server side

  • STATUS: error Could not save the registration or Reports directory is missing: the web server user cannot write to DATA_DIR. Check the owner, ACL and, with SELinux, the httpd_sys_rw_content_t label (ls -Z).
  • admin.php must be protected by web server authentication: the .htaccess login is not active. Check AllowOverride for the folder.
  • Check the Apache error log for PHP errors.
