Build from source

The agent is plain C++ against the Win32 API, built with nmake. No libraries beyond the Windows SDK.

What you need

  • Visual Studio 2022 or later (Community is fine) with the Desktop development with C++ workload
  • Inno Setup 6 for the installer, in its default folder C:\Program Files (x86)\Inno Setup 6

Build

Open an x64 Native Tools Command Prompt for VS (or run vcvars64.bat) in the source folder:

nmake               rem programs and the event message DLL
nmake installer     rem output\drra_setup_3.4.exe
nmake binzip        rem output\drra_3.4_bin_x64.zip
nmake clean

Development install

build.txt lists the individual compiler commands and the registry keys and commands for installing the service by hand, without the installer. send_test_report.exe reads the INI file next to it, so you can test against a development server from the build folder.
