Approve computers

A computer only sends reports after the server approves its certificate. Approve it on the admin page, or automatically with an enrollment token.

The admin page

Open admin.php in the upload pages folder, for example https://reports.example.com/windows_reporting_agent/upload/admin.php, and log in, with the web server login or, with login = drsm, the DRSM dashboard login. It lists every registered computer with its status, key fingerprint, registration and approval times, last report and last address, and the reports on disk that have no registration.

States

StatusMeaning
pendingRegistered, waiting for an admin. Its reports are refused.
approvedReports signed with its key are accepted.
revokedIts reports are refused. It stays listed until deleted.

Actions

  • Approve a pending or revoked computer. Check first that the key fingerprint matches the one in C:\ProgramData\DataReel\ReportingAgent\drra.log on that computer, so you know the request came from it.
  • Revoke a computer that was lost, stolen or retired.
  • Delete registration to forget the computer. It registers again with its next report.
  • Delete report to remove its saved report file.

Reinstalled computers

Each hostname can only be registered with one key. When Windows is reinstalled, the computer gets a new key and its registration is refused with key_mismatch. Delete its old registration on the admin page, and it registers again on its next report. Approve it again, or let the enrollment token do it.
