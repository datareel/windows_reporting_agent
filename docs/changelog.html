What's new

Release 3.4 is the first stable release of the DataReel Reporting Agent for Windows, for Windows 11, Windows Server 2022 and Windows Server 2025. It has everything from the 3.3 betas: release 3.3 beta 2 added hook uploads, and release 3.3 beta 1 was the first public release.

Release 3.6 Next release

  • AI-assisted guide: AGENTS.md, with CLAUDE.md and GEMINI.md, lets an approved enterprise AI agent assist your administrators with the report server, installs, approvals, upgrades, DRSM, building and troubleshooting. Human in the loop, never autonomous: people run or approve every step, and the agent never sees the enrollment token, a password, a key or server.ini. Also at datareel.com.
  • Settings file readable only by administrators: drra.ini holds the enrollment token, so setup now limits it to SYSTEM and Administrators (it was readable by every local user, like the rest of the program folder). Upgrades apply the change too. Edit it from an administrator editor.
  • Security design white paper: security_design.html, also at datareel.com.

Release 3.5 November 2026

  • Vulnerability scan: drra_svc.exe scan asks the Windows Update Agent for the updates not installed yet and sends a report right away; each security update has its KB number, MSRC severity and CVEs. The report has a VULNERABILITIES section in the Linux agent's format (source=wua), for the DataReel System Monitor windows/vulnerabilities plugin and Vulnerabilities page. Scans run by hand only unless [scan] enabled=1. See Vulnerability scan.
  • Downloads: drra_setup_3.5.exe and drra_3.5_bin_x64.zip.

Release 3.4 October 2026

  • Stable release of the 3.3 betas, for Windows 11, Windows Server 2022 and Windows Server 2025 (64-bit).
  • Downloads: drra_setup_3.4.exe, and drra_3.4_bin_x64.zip with the programs, message DLL, default settings and docs for installs without setup (see Development install). nmake binzip builds the zip.

Release 3.3 beta 2 October 2026

  • Hook uploads: send reports from other sources, such as a Defender scan run by hand or a backup job's result, with drra_svc.exe submit --hook <id> [--now] <file> or the upload spool folders. The server's new hook.php checks the signature and a manifest per hook, and the DataReel System Monitor shows each upload on the computer's page with its own rules. See Hook uploads.
  • New [uploads] settings and [https] hook_path; the report has an UPLOADS section. install_server.sh installs hook.php and hook_lib.php, and server.ini has a [hooks] section.

Release 3.3 beta 1 October 2026

Release 3.3 beta 1 turns an in-house tool, written for a deployment of 120 laptops, into a package anyone can install.

  • Signed uploads: each computer registers a certificate for a non-exportable machine key before it sends anything, and every report is signed. The server checks the signature, the approval state, the time and a one time nonce.
  • Admin page: approve, revoke and delete computers and reports, with a login and CSRF protection. It can use the DataReel System Monitor dashboard login (login = drsm).
  • Enrollment token: optional automatic approval for large rollouts.
  • Settings file: every setting is in drra.ini instead of the program code. The service reads it before each report.
  • Installer: a 64-bit setup.exe with server settings pages and command line switches for silent installs, upgrades that keep the settings, a restart-on-failure service, and an agent data folder limited to SYSTEM and Administrators.
  • Fleet status pages: status.php and report.php check every computer's last report for late check-ins, old Windows updates, Defender problems, and required and unwanted programs, with a live demo on a sample fleet.
  • Server install script: install_server.sh sets up the PHP pages, .htaccess, admin login and data folder, with a dry run first.
  • Delivery methods: signed HTTPS uploads, a Windows file share (CIFS) with a share login for sites without a domain (password encrypted with DPAPI), and SCP, alone or together.
  • Usage for trends: PERFORMANCE (CPU, memory, commit charge, uptime), DISK USAGE (each fixed drive) and NETWORK (adapter counters) sections as name=value lines for DRSM trend graphs, shown on the report page.
  • Every 15 minutes: reports every 15 minutes by default, set with report_interval_minutes or setup /INTERVAL=.
  • DataReel names: service DataReelReportAgent, programs in C:\Program Files\DataReel\ReportingAgent, data in C:\ProgramData\DataReel\ReportingAgent, so nothing installed looks like part of Windows. Setup moves earlier test builds (named Windows Reporting Agent) over.
